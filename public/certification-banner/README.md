# 考证现状广告图片

## 📋 文件说明

此目录用于存放"考证现状"广告横幅图片，该广告显示在系统主页面的学籍信息上方。

## ️ 图片规格要求

### 尺寸建议
- **推荐尺寸**: 1200px × 400px（3:1比例）
- **最小宽度**: 800px
- **最大高度**: 500px
- **响应式适配**: 
  - 移动端显示高度: 180px
  - 桌面端显示高度: 200px

### 文件格式
支持以下格式（按优先级排序）：
1. **PNG** - `certification-banner.png` (推荐，支持透明背景)
2. **JPG/JPEG** - `certification-banner.jpg` (备选)
3. **SVG** - `certification-banner.svg` (矢量图，无限缩放)

### 文件大小
- PNG/JPG: 建议 < 500KB
- SVG: 建议 < 100KB

### 颜色方案
- **主色调**: 蓝色系 (#3B82F6 或类似)
- **文字颜色**: 白色 (#FFFFFF)
- **对比度**: 确保文字与背景有足够对比度（WCAG AA标准）

## 🎨 设计内容建议

### 必需元素
1. **标题**: "考证现状"（醒目大字）
2. **副标题/描述**: "参与考证需求调研，分享备考经验，共筑高效考证指南"
3. **装饰元素**: 可根据主题添加相关图标或插图

### 可选元素
- 证书、文凭等教育相关图标
- 人物插画或抽象图形
- 渐变色背景增强视觉效果

## 📝 替换步骤

1. **准备图片**
   - 按照上述规格设计您的广告图片
   - 确保图片质量清晰，文字可读

2. **放置图片**
   ```bash
   # 将图片放置在 public 目录下
   cp your-image.png /home/test/edit-my-degree/public/certification-banner.png
   ```

3. **验证显示**
   - 启动开发服务器: `npm run dev`
   - 访问主页查看广告是否正常显示
   - 测试不同屏幕尺寸下的响应式效果

4. **清除缓存**（如有需要）
   ```bash
   # 清除浏览器缓存或使用 Ctrl+Shift+R 强制刷新
   ```

## ⚠️ 注意事项

1. **内容安全区域**
   - 重要文字应距离边缘至少 20px
   - 避免在图片四角放置关键信息

2. **响应式测试**
   - 在移动端（≤768px）和桌面端分别测试显示效果
   - 确保文字在小屏幕上仍然清晰可读

3. **性能优化**
   - 使用图片压缩工具（如 TinyPNG）减小文件大小
   - 避免使用过大的图片影响页面加载速度

4. **版权说明**
   - 确保使用的图片拥有合法版权或授权
   - 避免使用侵权素材

## 🔧 故障排查

### 图片不显示
- 检查文件名是否正确: `certification-banner.png`
- 确认文件放置在 `public/` 目录下
- 检查浏览器控制台是否有404错误
- 尝试清除浏览器缓存

### 图片变形
- 调整图片尺寸比例接近 3:1
- 检查CSS中的 `object-fit: cover` 属性是否生效

### 文字模糊
- 提高图片分辨率
- 确保文字大小在缩小后仍可辨认
