## 🎨 广告窗口特性

### 样式设计
- **背景色**: 蓝色 (`bg-blue-500`)
- **圆角**: 中等圆角 (`rounded-lg`)
- **阴影**: 默认阴影 + hover时加深效果
- **响应式高度**:
  - 移动端: 180px
  - 桌面端: 200px

### 交互功能
- **可点击**: 点击后显示Toast提示（可扩展为跳转链接）
- **Hover效果**: 阴影加深，提升视觉反馈
- **错误处理**: 图片加载失败时自动显示文字内容

### 响应式适配
- 使用 Tailwind CSS 的响应式工具类
- 自动适配不同屏幕尺寸
- 保持图片比例不变形（`object-cover`）

## 📝 后续操作建议

### 替换实际广告图片
1. 按照 `public/certification-banner/README.md` 中的规格要求设计图片
2. 将设计好的图片命名为 `certification-banner.png`
3. 放置在 `public/` 目录下替换现有占位图
4. 清除浏览器缓存并刷新页面验证

### 扩展功能（可选）
如需添加跳转功能，修改 `onClick` 事件：
```typescript
onClick={() => {
  navigate('/certification'); // 跳转到考证相关页面
}}
```
